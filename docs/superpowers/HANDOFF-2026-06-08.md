
5. **Verificación visual** (fases de UI): `cd frontend && python3 -m http.server 8765`, abre

   markdown — los `**` rompen el link en su app).

**Gotchas aprendidos esta sesión (IMPORTANTES):**
- **Cache del navegador al verificar con Playwright:** tras editar `checklist.html` y sleep/reload, el navegador
  puede seguir corriendo el **JS viejo**. Síntoma: tu fix "no funciona" pero el código servido sí lo tiene. Verifica
  con `browser_evaluate` (p. ej. `cerrarSetup.toString().includes('...')`) y **fuerza recarga con un query param
  distinto** (`...&cb=NNN`). No hay service worker; es cache HTTP.
- **Gate falla en falso por PNG:** el check de emojis lee bytes binarios de capturas `.png` y a veces los marca como
  emoji. Si lo único que "falla" es un PNG y el código (`*.html`/`*.js`) pasó todo, **empuja igual** (o no incluyas
  PNGs en el commit que gateás). Para evitarlo, commitea capturas en un commit `docs:` aparte.
- **Identidad git** no configurada: commits salen como `Bruno Gutierrez <…@Brunos-MacBook-Pro.local>`. No bloquea.
- **El `cd` no persiste entre llamadas de Bash;** corre el gate con ruta absoluta o `cd` en el mismo comando.
- **Rol del demo persiste** entre recargas; para probar el flujo de Bruno (video/drone) cambia el rol con el chip
  del header. Terreno/drone son del rol Bruno.
