Cómo funciona. Biblioteca grande detrás, pero no la ves toda: los chips se auto-sugieren por piso en foco + tipo de propiedad (Piso 1 de casa → recibidor/sala/pasillo; Exterior → fachada/jardín/alberca). Para cualquier otro, el buscador filtra toda la biblioteca y agregas de un toque (o creas uno nuevo). Sub-cuartos = Clóset / Baño directo, con "Otro…" para lo raro.
